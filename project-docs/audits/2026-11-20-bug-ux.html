The cleanest app of this round on bugs: purchase, restore and the drills held up, and nothing above low severity was found. The worst is Timed Challenge, which throws the score away on any exit except the clock running out, and whose clock stops while the app is in the background. A run that crosses midnight is credited to the next day, shown by test. The payoff is on the UX side: a locked tile or drill forgets what was tapped, so buying drops the customer back on the same list; starting the trial in onboarding ends in a generic tour; and the free Home leads with a tagline, two unlabeled zeros, a 'swipe for more' cue and a tile cut off mid-word.

B1

Timed Challenge loses the personal best on any exit except the clock, and the timer does not follow real time

lowconfirmedstate
Impact

A good run is thrown away by an accidental back swipe, and a suspended app gets extra time. Item accuracy is still recorded, so only the challenge best is affected.

How it happens
  1. Become a member and open Timed Challenge.
  2. Answer several questions correctly, then swipe back from the left edge (the timed mode has no Finish button) or get a phone call.
  3. The score is never saved; best score stays as before. After a call the run resumes with the old seconds left because each loop only subtracts 1.

B2

A run that crosses midnight is credited to the next day: streak resets and tomorrow's Get Started is marked done

lowconfirmedstate
Impact

A player whose evening session runs past midnight loses a multi-day streak and their next morning's Get Started. The Cribbage Minute is the one place the start day is kept (result stored under the challenge's own dayKey), but its streak credit and weekly count still land on the finish day, so a Saturday-night Minute finished after midnight counts toward the next week.

How it happens
  1. Practise on Mar 1, 2 and 3 so the streak is 3.
  2. On Mar 4 at 23:55 tap Get Started (the deck is built at that moment).
  3. Answer slowly and tap Finish at 00:03 on Mar 5.
  4. Finish stamps the day with Date() at the end: markQuickSessionCompleted() and recordSession(drillID:) both use Mar 5.
  5. Home now shows streak 1 (last active Mar 3, today Mar 5, gap 2) and the Get Started card for Mar 5 reads done until Mar 6.

high payoffOctober UX-3 still open

It is the first thing a new customer sees after the value pages. The owner's rule is that it must not read as templated. Noted as frozen: membership-and-trial.md says this page is a fixed Mahj layout and any change needs Jack's go-ahead.

Suggested change

On the skill page delete both helper lines (the disabled button is enough). On the trial page, if Jack opens it, cut the list to the two lines that differ from the free app and drop the sparkles circle.
